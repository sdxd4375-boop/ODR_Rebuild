## 1. 先看结论

当前目录不是只有最初的 LangGraph 核心项目，而是：

1. 原始核心研究图；
2. 自建 FastAPI 后端、React 前端、PostgreSQL 持久化扩展；
3. 历史 legacy 实现；
4. 本地开发环境、缓存、构建产物和分析文档。

建议先停止 LangGraph、Uvicorn、Vite 和相关 Python 进程，然后按以下顺序处理：

```powershell

Remove-Item -Recurse -Force G:\Code\open_deep_research\.ruff_cache
```

